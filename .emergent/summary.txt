**Key Technical Concepts**
- **Visual Content Editor**: An in-app editing interface that allows non-technical users to modify website content in real-time.
- **Content Override System**: An architectural pattern where the application first attempts to load content from a dynamic source (MongoDB). If no content is found for a given key, it falls back to a default static version from the codebase ().
- **Central Content Registry**: A single file () that defines every editable piece of content on the site. This decouples the editor logic from the components themselves.
- **Server-Side Image Uploads**: A secure method for handling file uploads where the image is sent to the backend, saved on the server, and the resulting URL is stored, preventing client-side exposure of credentials or direct filesystem access.
